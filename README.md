# 避难所3 统计面板

一个给《最后的避难所3》（KK 对战平台）用的实时经济统计小工具。

开局之后想知道队友资源攒了多少、谁快没饱食度了、谁感染高了？这个面板帮你一眼看全，方便队伍内分工协调。

---

## 能干啥

- **实时看全队数据**：5 个玩家的普通资源、稀有资源、饱食度、感染度，一个面板全显示
- **累计统计**：不只看当前值，还统计每个人这一局总共攒了多少资源
- **退款识别**：买东西退款不会被算成"白赚"，累计数据更准
- **自动识别在场玩家**：不用手动设置，谁在玩自动认出来
- **纯只读**：只看不改，不碰游戏任何数据

---

## 怎么用

1. 先开游戏，进入一局
2. 双击运行本工具（需要管理员权限，因为要读游戏内存）
3. 工具会自动连上游戏，面板开始显示数据
4. 数据没出来、或者换了一局，按 `F5` 刷新（快捷键可在界面里改）
5. 想重新开始统计累计，点「重置累计」

---

## 它大概是怎么做到的

一句话：**读游戏内存**。游戏运行时所有数据都在内存里，工具去对应的位置把数字读出来显示，全程只读、不写。

几个稍微有意思的点（不懂也不影响用，写出来给好奇的人看）：

- **指针定位**：资源数据在内存里的位置每局都会变，工具靠一串"指针链"动态找到它，不是写死的固定地址
- **饱食度智能锚定**：饱食度的地址特别爱漂移，过一两天就失效，所以改成以感染度地址为基准动态推算，稳定性好很多
- **玩家块自动反查**：多人局里每个玩家的资源块是分散存放、间距还会变的，工具拿已知的玩家块当"模板"提取结构特征，再在内存里一块一块"走"出其他玩家的位置，所以不管几个人都能正确对上号

## 注意事项

- **这是纯只读工具**：不修改游戏、不改数值、不去战争迷雾、不开视野，只是把游戏里本来就有的数据显示出来
- 请遵守你所在对战平台的规则，本工具定位是队伍内信息协调参考
- 杀毒软件可能报毒——读取游戏内存的程序基本都会被误报，这是这类工具的通病。介意的话可以直接看源码，或者自己编译
